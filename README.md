# USA Financial Credit Risk Dashboard

## Project Overview

This project focuses on automating and analysing large-scale USA financial customer data using Python, Pandas, and Power BI. The main objective was to reduce manual workload, minimize data processing errors, and generate actionable business insights through interactive dashboards and analytics.

The project simulates a real-world business scenario where multiple financial datasets are received daily from different survey teams. The workflow was automated to streamline data collection, merging, cleaning, and analysis processes.

---

## Business Problem

The organization faced several operational challenges:

* Manual downloading and processing of 25+ files daily
* High time consumption in combining and cleaning datasets
* Increased operational cost due to additional employees
* Frequent data manipulation errors
* Delays in dashboard generation and reporting

The company required an automated and scalable solution to improve efficiency and support decision-making.

---

## Solution Implemented

An automated ETL and analytics workflow was developed using Python and Power BI.

### Key Solutions:

* Automated financial data collection from Google Drive
* Combined multiple CSV/Excel files into a single dataset
* Performed data cleaning and transformation using Pandas
* Built interactive Power BI dashboards
* Generated customer segmentation and credit risk insights
* Calculated LTV (Lifetime Value) scores for customer targeting
* Analysed payment behaviour, loan trends, and credit utilisation
